## 🚀 Featured Projects

*Graduate team projects from Duke, where I worked as Machine Learning Engineer & Team Lead (Jan – May 2022), plus related work.*

### Computer Vision

**Treat It or Leave It? Malignancy Diagnosis of Skin Lesions** · [Slides (PDF)](https://github.com/tongtz/tongtz.github.io/blob/main/docs/presentation.pdf)
A clinical decision-support system for diagnosing lesions from dermatological images (ISIC 2016 plus a clinical smartphone dataset). It compares HOG features with an SVM against a ResNet50 CNN, and uses Faster R-CNN to locate and crop lesions, which improved predictions over whole images. *Duke AIPI 540, with Christine Park & Hank Chen.*

**Photo to Avatar** · [Slides (PDF)](https://github.com/tongtz/photo2avatar/blob/main/presentation.pdf)
Unpaired image-to-image translation with UGATIT that turns a real portrait into a cartoon avatar that keeps the person's features, giving people a personalized profile image without exposing their photo. Trained on 3,400 portraits and 3,400 anime images (Danbooru2021).

### Natural Language Processing

**Question Answering on Product Reviews** · [Slides (PDF)](https://github.com/tongtz/QuestionAnswering/blob/main/Presentation.pdf)
Extractive question answering on the SubjQA dataset. A fine-tuned DistilBERT Transformer reached about **70% F1**, versus about 30% for a sentence-embedding + logistic regression baseline. Includes a Streamlit demo. *With Wade Wei.*

**Text-to-SQL with a Hybrid Ranking Network** · [Code](https://github.com/1999Lyd/test-to-sql-model-implementation)
A team implementation of HydraNet, a hybrid ranking network for text-to-SQL, trained and evaluated on the WikiSQL benchmark, with a Docker image for reproducing experiments.

### Recommendation Systems

**Dating App Profile Recommender** · [Code](https://github.com/bkenan/dating_recsys)
A team project that tackles the cold-start problem by computing similarity between new and existing users, with filtering and TF-IDF on text inputs. Built on the OkCupid profiles dataset, with a Streamlit app.

### Data Analytics & Visualization

**Engineer-Related Employment Trends in the United States** · [Report (PDF)](https://github.com/tongtz/employment-trend/blob/main/Analysis%20of%20Engineer-related%20Employment%20Trend%20in%20United%20States%20.pdf)
